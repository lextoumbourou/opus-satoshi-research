# Satoshi research

Working repo for the "Can Opus 5.5 find Satoshi Nakamoto?" experiment.

- `log.md`: research log (what was tried, when, and the result)
- `notes/`: write-ups and findings, with every claim labelled
- `data/`: primary sources we can share (mailing-list and forum archives, published emails, release archives, the blockchain, keys) and our derived data
- `scripts/`: analysis scripts, which can be re-run against `data/`

Evidence labels used throughout:
- **VERIFIED**: I checked the primary source myself (URL/file given)
- **REPORTED**: someone else says so (source given); I haven't checked the primary
- **INFERENCE**: my own reasoning, with a confidence level (low/medium/high)

## Sources not included

Published works we consulted (news and magazine articles, blog essays, academic papers, court filings, article images, video transcripts, tweets and Wikipedia copies) are not in this repository. [`data/SOURCES.md`](data/SOURCES.md) explains the policy, and [`data/sources.csv`](data/sources.csv) lists every such file with its SHA-256 and where to get it. Some notes and logs still refer to those files by their old paths under `data/`; look the path up in `sources.csv`.
