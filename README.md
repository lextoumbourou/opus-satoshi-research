# Satoshi research

Working repo for the "Can Opus 5.5 find Satoshi Nakamoto?" experiment.

- `log.md`: research log (what was tried, when, and the result)
- `notes/`: write-ups and findings, with every claim labelled
- `data/`: downloaded primary sources (emails, posts, release archives, PDFs, keys)
- `scripts/`: analysis scripts, which can be re-run against `data/`

Evidence labels used throughout:
- **VERIFIED**: I checked the primary source myself (URL/file given)
- **REPORTED**: someone else says so (source given); I haven't checked the primary
- **INFERENCE**: my own reasoning, with a confidence level (low/medium/high)
