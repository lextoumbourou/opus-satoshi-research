# Satoshi Nakamoto corpus (machine-readable)

Everything Satoshi Nakamoto is known to have written, collected from primary or near-primary sources into one JSONL file with the most precise timestamps available. That covers his public posts, his published private emails, his SVN commit messages, his code comments and the whitepaper.

- **Built:** 2026-09-26. All downloads were made that day, roughly 01:45 to 03:00 UTC. Individual fetch times are in the `.meta.json` / `fetch_meta.json` / `FETCH_LOG.json` files under `raw/`.
- **Main output:** [`posts.jsonl`](posts.jsonl), one JSON object per Satoshi-authored item (956 items).
- **Per-source intermediates:** [`intermediate/`](intermediate/). They use the same schema, and `build_corpus.py` merges them.
- **Raw downloads:** [`raw/`](raw/). HTML, mbox, .eml, PDFs and archives, saved exactly as fetched.
- **Scripts (re-runnable):** [`../../scripts/corpus/`](../../scripts/corpus/).
- **Summary stats:** [`summary.md`](summary.md), regenerated by `build_corpus.py` and also spliced into the end of this file.

Only items written by Satoshi go into `posts.jsonl`. Other people's messages survive only in the raw files, and as quoted text inside `text_raw`.

## Record schema (`posts.jsonl`)

| field | meaning |
|---|---|
| `id` | Stable id, e.g. `metzdowd-014815`, `bitcointalk-msg29479`, `svn-r199`, `bitcoin-list-21033408`, `p2p-research-001347`, `p2pfoundation-ning-topic-9402`, `email-malmi-0015`, `code-bitcoin-0.1.0-src_main.cpp` |
| `source_type` | `email` (private email) \| `forum` \| `mailing_list` \| `p2pfoundation` \| `svn_commit` \| `code_comment` \| `whitepaper` |
| `venue` | List address, forum and board, "private email", or SVN repository |
| `recipient` | List name or private correspondent address; null for forum posts. Private emails also have `correspondent` (the person's name). |
| `thread` | Subject or topic title |
| `timestamp_utc` | ISO 8601 UTC, `YYYY-MM-DDTHH:MM:SSZ`. **Null if the time zone is unknown or there is no timestamp.** |
| `timestamp_raw` | The timestamp exactly as it appears in the source, including any zone text |
| `timestamp_precision` | `second` \| `minute` \| `unknown` \| `none` |
| `timestamp_source` | Which field the timestamp came from, and how the zone was determined |
| `timestamp_tz_raw` | The zone or offset as displayed in the source (e.g. `+0800`, `+0100`, `UTC`). Null if none is displayed. |
| `timezone_basis` | `explicit`: zone or offset is printed in the source (Date: header, epoch, PDF offset). `verified`: no zone printed, but the display zone was established empirically (bitcointalk, SourceForge, Ning = UTC). `inferred`: zone deduced indirectly. `assumed`: zone assumed without verification. `unknown`: local time known, zone unknown (`timestamp_utc` null). `none`: no timestamp. |
| `authenticity` | `accepted` or `disputed`. Only the 2014 "I am not Dorian Nakamoto" Ning post is `disputed`. |
| `timestamps_other` | Other timestamps for the same item, as `[{label, raw, utc}]`: Received: hops, list-archive times, SNI's date, bitcointalk "Last Edit", sender Date: headers from other copies, and so on |
| `url` | Primary URL |
| `raw_path` | Repo-relative path of the raw file the record was parsed from |
| `whitespace_preserved` | `true` / `false` / `"partial"`: whether `text_raw` keeps the source's exact spacing |
| `whitespace_notes` | How whitespace was handled for this item |
| `text` | Satoshi's own words only. Quoted text from others is stripped where feasible. |
| `text_raw` | The full body including quotes, with whitespace as in the rawest source |
| `notes` | Caveats |
| extras | Source-specific fields, including: `subject`, `from_address`, `to_address`, `message_id`, `in_reply_to`; `timestamp_first_received_utc` (metzdowd: the send service's own Received: time); `timestamp_list_arrival_utc` (bitcoin-list: SourceForge arrival); `html_raw` (forum HTML as served); `embedded_local_timestamps` (bitcointalk posts containing `diff -u` headers); `svn_revision`, `git_hashes`; `same_text_as` (other ids with the same text); `duplicate_message_of` (the same email distributed to two lists) |

## Sources

### 1. Satoshi Nakamoto Institute (SNI) data: index and cross-check

- **Repo:** https://github.com/NakamotoInstitute/nakamotoinstitute.org, commit `c412eb84a1d97df9114a6bf4dea300820965c0a7` (2026-07-13). Shallow-cloned and trimmed to `server/data/` in `raw/sni-repo/`; see `raw/sni-repo/REVISION.txt`.
- **`emails.json`:** 72 list emails, 39 of them by Satoshi (18 cryptography, 16 bitcoin-list, 5 p2p-research).
- **`forum_posts.json`:** 3,845 posts in the threads Satoshi took part in. 543 are by Satoshi: 539 on bitcointalk and 4 on P2P Foundation Ning.
- **How it is used:** SNI is a secondary source. It supplies pipermail and SourceForge URLs, and serves as a cross-check for dates and text. Rawer copies were used wherever they exist.
- **Discrepancies found:**
  - SNI's five p2p-research dates are all **7 minutes too late (+420 s)**. They look like a CET→UTC conversion done with the Berlin local-mean-time offset (+0:53) instead of +1:00.
  - SNI's JSON has lost backslashes and tabs inside code blocks in 6 bitcointalk posts.
  - SNI's bitcointalk, bitcoin-list and Ning dates otherwise agree with our raw sources to the second (or the minute, for Ning).

### 2. cryptography@metzdowd.com (Oct 2008 – Jan 2009): 18 posts

- **Rawest copy:** Gmane NNTP (`news.gmane.io`, group `gmane.comp.encryption.general`, which is the metzdowd list).
  - These are full RFC 822 messages with every relay hop. Gmane renames `Received:` to `Original-Received:`.
  - Saved in `raw/gmane/gmane.comp.encryption.general/<artnum>.eml` by `fetch_gmane.py`.
  - `raw/gmane/scan.tsv` lists every article in the scanned groups whose From: mentions satoshi, vistomail or anonymousspeech. That includes 2015+ impostor posts, which were **not** downloaded and are not used.
- **Second copy:** Mailman monthly text archives from `https://www.metzdowd.com/pipermail/cryptography/`, covering 2008 October–December and 2009 January–February (`.txt.gz`), saved in `raw/metzdowd/`. After quoted-printable decoding, all 18 bodies are byte-identical to the Gmane bodies, apart from pipermail's `@`→` at ` address obfuscation.
- **URLs:** pipermail HTML message pages. The message numbers come from SNI, matched on the Date: header.
- **Timestamp:** the **Date: header** (e.g. `Sat, 01 Nov 2008 02:10:00 +0800`), converted using its own offset.
  - All of Satoshi's posts carry `+0800`. That is the offset of the sending service (anonymousspeech.com / vistomail.com, Chilkat mailer, server 124.217.253.42), not necessarily Satoshi's.
- **Relay timestamps:** `timestamp_first_received_utc` is the service's own Received: time (`server123` → anonymousspeech.com).
  - It is 3–155 minutes **after** the Date: header in these 18 posts. The private copies (Trammell, Finney) show the same pattern.
  - Our reading (an inference) is that Date: is when the message was composed or submitted in the webmail interface, and Received: is when it was actually sent.
  - `timestamps_other` also holds the metzdowd relay hops (US Eastern), the pipermail envelope `From ` line (list-server local time, EST/EDT) and Gmane's NNTP-Posting-Date.
- Three Date: headers end in `:00` seconds.
- metzdowd-015014 (2009-01-16) was Cc'd to bitcoin-list as well. The bitcoin-list copy, `bitcoin-list-21356305`, is kept but flagged `duplicate_message_of`, and is left out of the histograms.

### 3. bitcoin-list@lists.sourceforge.net (Dec 2008 – Dec 2010): 16 posts

- **Access:** sourceforge.net serves a Cloudflare challenge to scripts, and it was not bypassed. All pages come from Wayback Machine raw (`id_`) captures:
  - 11 posts have the modern SourceForge message page (`raw/sourceforge_bitcoin_list/allura_message/`).
  - 5 have only a legacy (pre-2013) SourceForge thread or month page (`legacy_thread/`, `legacy_month/`).
  - Cross-checks: the lugaxker/nakamoto-archive transcription (`lugaxker_bitcoin-list-archive.txt`, pinned commit) and SNI. The 16 posts are the complete set; all three sources agree.
- **SourceForge time zone:** SourceForge displays `YYYY-MM-DD HH:MM:SS` with no zone.
  - Compared against the 37 bitcoin-list messages from 2011–14 that Gmane also archived with full headers (`raw/sourceforge_bitcoin_list/gmane_bitcoin_user/`, `intermediate/bitcoin_list_sf_tz_anchor.json`), the SourceForge time equals, to the second, **the UTC arrival time at SourceForge's list server**, not the sender's Date:.
  - It is stored as `timestamp_list_arrival_utc`.
- **`timestamp_utc`:**
  - Where another copy gives the sender's Date: header, that is used (`timezone_basis: explicit`). There are 8 such posts: 7 from Martti Malmi's received copies, and 21356305 from the Trammell and Gmane copies.
  - Otherwise it is the SourceForge arrival time (`verified`).
  - Measured delay from Date: to arrival: 16 s to 3 min for most GMX posts; 28 min for the 0.3.6 alert; 2 h 32 min for one vistomail post.
  - The SourceForge-only times from Dec 2008 to Mar 2009 (vistomail era) are therefore **upper bounds** on send time.
- **Whitespace:** the `<pre>` bodies are preserved.
  - Satoshi's GMX/Thunderbird posts use format=flowed, so a trailing space before a line break marks a soft wrap.
- Scripts: `fetch_bitcoin_list.py`, `fetch_bitcoin_list_gmane_anchor.py`, `parse_bitcoin_list.py`.

### 4. p2p-research mailing list (P2P Foundation, Feb 2009): 5 posts

- **Source:** the raw pipermail monthly archive `2009-February.txt.gz`, via the Wayback Machine, in `raw/p2p_research/`.
  - The original host (p2pfoundation.net/backups) returns 404, and the diyhpl.us mirror is behind an anti-bot challenge that was not bypassed.
  - The archive is byte-identical to lugaxker's copy of the diyhpl.us mirror.
  - No Satoshi posts in March 2009.
- **Timestamp:** the sender's **Date: header**. All five read `+0000` (from satoshin@gmx.com, Thunderbird).
  - The Thunderbird Message-ID hex field decodes to the same second in each case.
- **Whitespace:** preserved (raw mbox). Non-ASCII characters appear as `?`.

### 5. P2P Foundation Ning forum: 4 posts (3 from Feb 2009, plus the disputed 2014 post)

- **Source:** p2pfoundation.ning.com via Wayback captures, in `raw/p2pfoundation/`.
  - Covers the thread "Bitcoin open source implementation of P2P currency" (topic 9402) and Satoshi's replies.
  - Also the 2014-03-07 "I am not Dorian Nakamoto." (comment 52186), flagged `authenticity: disputed` and excluded from the histograms.
- **Time zone:** Ning shows minute-precision times with no zone. It was established to be **UTC** from Wayback captures that show relative times:
  - A capture at 2009-02-21 02:48:57Z says "17 hours ago" for a reply shown elsewhere at 8:53am.
  - A capture at 2014-03-07 02:12:21Z says "54 minutes ago" for the post shown at 1:17.
  - The first Ning post (22:27) also went out by email to p2p-research at 22:30:54 +0000.

- The Feb 2009 announcement text appears in both Ning and p2p-research (`same_text_as`).

### 6. bitcointalk.org, user `satoshi` (u=3): 539 posts (2009-11-22 → 2010-12-12)

- **Fetching:**
  - `fetch_bitcointalk.py` fetched the 27 showPosts pages of 20 posts each (`https://bitcointalk.org/index.php?action=profile;u=3;sa=showPosts;start=N`), one request every 3 s. Raw HTML is in `raw/bitcointalk/showposts/`, with fetch time and HTTP Date in a `.meta.json` per page.
  - `fetch_bitcointalk_topics.py` then fetched the 293 topic pages holding those posts (`index.php?topic=T.msgM`, one request every 3 s) into `raw/bitcointalk/topics/`. Topic view shows the **"Last edit"** time, which showPosts doesn't.
  - 105 of Satoshi's posts show a last edit: 103 by satoshi, 1 by theymos, 1 by sirius-m. These are in `timestamps_other` (label `bitcointalk 'Last Edit'`, with `edited_by`) and in `intermediate/bitcointalk_edits.json`. Only the *last* edit is visible.
  - Post times in topic view match showPosts for all 539 posts.
- **Counts:** the profile says "Posts: 575", but only 539 are listed to guests. The other 36 are presumably deleted, or in boards hidden from guests, and are not recoverable here. The 539 are exactly the message ids SNI has.
- **Time zone:** SMF 1.1.19 renders times in the viewer's zone.
  - For a guest, the header clock on every fetched page matched the HTTP `Date:` response header to within 1 s. That held on all 27 showPosts pages (`raw/bitcointalk/display_zone_check.tsv`) and all 293 topic pages.
  - Fetched in late September, when UK/EU/US summer time is in force, the display was UTC+0. So the guest display zone is **UTC, with no DST**.
  - SMF stores unix epochs, so the conversion is exact: `timestamp_utc` = displayed time.
- **Independent consistency check:** SVN r199 "added some DoS limits, removed safe mode" is at 2010-12-12T18:20:36Z (git-svn, UTC).
  - The forum post announcing that build shows 06:22:33 PM, two minutes later.
  - Its Last Edit is 2010-12-13 16:45:48, 19 minutes after SVN r201 "-- version 0.3.19 release" (16:26:14Z).
  - The profile's "Last Active" is 16:45:41 that day.
- **Whitespace:** SMF encodes each extra space as `&nbsp;` (two spaces become ` &nbsp;`), newlines as `<br />`, and tabs as a `white-space: pre` span. Space runs therefore survive in the HTML.
  - `text` and `text_raw` are rebuilt from the HTML: `<br />` → newline, `&nbsp;` → space.
  - Quotes become `[quote author=.. date=..]..[/quote]` (kept in `text_raw`, stripped from `text`), code becomes `[code]..[/code]`, links whose text differs from the URL become `[url=..]..[/url]`, and smileys are mapped back to their codes.
  - The exact served HTML is kept in `html_raw`. The original BBCode is not available to guests: `quotefast` requires a logged-in session, and none was used.
- **Caveats:**
  - Satoshi's first post (2009-11-22) opened the SMF forum. The earlier forum at `bitcoin.sourceforge.net/boards/` is **not archived** anywhere we could find.
  - Some Nov–Dec 2009 posts are **reposts** of older threads from it, so they carry the repost time.
  - Two posts (msg9359, msg15116) contain `diff -u` headers with the local modification times of Satoshi's files, in `embedded_local_timestamps`. No zone is stated; these are recorded as data only.

## Time zone handling (summary)

| source | `timestamp_utc` taken from | zone established by |
|---|---|---|
| metzdowd | sender Date: header | offset printed in the header (+0800, the send service's zone) |
| bitcoin-list | sender Date: (8 posts) or SourceForge archive time (8) | printed offset; SourceForge time = UTC arrival, checked against 37 Gmane messages |
| p2p-research | sender Date: header | offset printed (+0000) |
| Ning | displayed time (minute) | UTC, from Wayback relative-time anchors |
| SourceForge news | displayed time | "UTC" printed |
| bitcointalk | displayed time (second) | guest display = UTC, checked against the HTTP Date header on 320 pages |
| SVN | git-svn author date | UTC epoch |
| private email | Date:/Sent: lines | explicit where printed (Malmi, Trammell, Back, Finney/CoinDesk); **inferred** (Finney/WSJ, Andresen) or **assumed** (Hearn) otherwise; null if unknown (Dai, Matonis, Hanyecz) |
| whitepaper | PDF CreationDate | offset printed (-06:00) |

Always check `timezone_basis` before using `timestamp_utc`. Histogram A below uses only `explicit` and `verified` items.

The email Date: header is written by the sender's client or webmail service, and can precede actual sending: 3–155 min for Satoshi's vistomail/anonymousspeech mail. Where relay times exist they are in `timestamps_other`, `timestamp_first_received_utc` (metzdowd) and `timestamp_list_arrival_utc` (bitcoin-list).

## Known gaps and caveats

- **bitcointalk:** 36 of the 575 posts counted on the profile are not visible to guests. BBCode source isn't available. Only the *last* edit time of a post is visible.
- **Old forum:** the pre-November-2009 SourceForge-hosted forum (`bitcoin.sourceforge.net/boards/`) is not archived. Some bitcointalk posts from Nov–Dec 2009 are reposts from it.
- **Blocked or down during the run:**
  - sourceforge.net (Cloudflare challenge) and diyhpl.us (go-away bot challenge): no challenge was bypassed, so both were reached only through Wayback captures and third-party mirrors.
  - The Internet Archive was intermittently offline; the scripts retry.
- **Whitepaper:** only the March 2009 revision was captured; the October 2008 original PDF was not.
- **Private emails:**
  - Only what recipients chose to publish, often without full headers. Malmi published only Date/From/To/Subject; Hearn and Finney/WSJ published client-rendered dates with no zone.
  - Satoshi's emails with Andresen, Hearn and others shown at COPA v Wright exist only as screenshots, where published at all.
  - Correspondence with Hal Finney is incomplete.
- **Email Date: headers vs sending:** Date: headers from Satoshi's anonymous-webmail period (Oct 2008 – Mar 2009) can precede actual sending by minutes to hours.
- **Hal Finney's server clock:** it appears ~26–37 min off (see the Finney/CoinDesk notes).
- **Duplicates across venues:**
  - One email Cc'd to two lists (metzdowd-015014 = bitcoin-list-21356305) is flagged `duplicate_message_of`.
  - The same announcement text posted on Ning and on p2p-research, and the 0.3 release posted on bitcoin-list and on bitcointalk, are linked via `same_text_as` but kept as separate writing events.
- **Excluded impostors:** later "Satoshi" posts (2015+ bitcoin-dev and cryptography impostors, Gmane cypherpunks 2022–25) are excluded. They are listed only in `raw/gmane/scan.tsv`.
- **Disputed:** the 2014 Ning post is kept but flagged `authenticity: disputed`.
- **Code comments:** no usable timestamps.

## How to rebuild
